Política de privacidade

Última atualização: 24 de novembro de 2026.

Quais dados o app acessa

Com a sua autorização, o Meu Cinema usa a permissão drive.readonly do Google para ler os nomes, pastas, miniaturas e o conteúdo dos arquivos de vídeo e legenda do seu Google Drive, e o endereço de e-mail da conta, só para mostrar qual conta está conectada.

Como os dados são usados

Os dados são usados apenas para montar a sua biblioteca e reproduzir os vídeos no seu aparelho. O app não altera, não apaga e não envia arquivos para o seu Drive.

Armazenamento e compartilhamento

  • O token de acesso do Google fica guardado no Keychain do seu aparelho.
  • A lista de vídeos, o progresso de reprodução e as capas ficam salvos apenas no próprio aparelho.
  • Nenhum dado do Google é enviado a servidores do desenvolvedor ou de terceiros. Os títulos dos filmes são consultados no The Movie Database (TMDB) para buscar capas e sinopses.
  • Os dados não são vendidos, compartilhados nem usados para publicidade.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como remover o acesso

Você pode desconectar a conta nos Ajustes do app a qualquer momento, ou revogar o acesso em myaccount.google.com/permissions. Apagar o app remove todos os dados guardados no aparelho.
